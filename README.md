# 📋 Sistema de Cadastro de Usuários

## 🚀 Sobre o Projeto

Este projeto foi desenvolvido como parte da **Formação FullStack DevClub**, com o principal objetivo de aprofundar os conhecimentos no ecossistema **React** e em bibliotecas essenciais para o desenvolvimento front-end moderno.

A aplicação consiste em um sistema completo de gerenciamento de usuários, integrando uma interface limpa e responsiva a um backend local.

## ✨ Funcionalidades

- **Cadastro de Usuários:** Formulário intuitivo para registro de novos usuários contendo campos para **Nome**, **Idade** e **E-mail**.
- **Validação de Dados:** Verificação das informações preenchidas antes do envio para garantir a integridade dos dados.
- **Listagem Dinâmica:** Tela dedicada para visualizar todos os usuários cadastrados de forma organizada.
- **Comunicação com API:** Integração com um backend local para persistência e resgate das informações.
- **Navegação Fluida:** Rotas estruturadas para transição entre as páginas da aplicação.

## 📦 Como Executar o Projeto

Clone este repositório em sua máquina e siga os passos abaixo:

```bash
# Clone o repositório
git clone https://github.com/willames-alves/-register-users-devclub.git

# Acesse a pasta do projeto
cd nome-do-repositorio

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
```
